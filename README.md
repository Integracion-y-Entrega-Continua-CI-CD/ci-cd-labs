En adelante escribiremos informacion relevante a este proyecto de pipeline.

## Flujo de trabajo

Este repositorio utiliza una estrategia de branching basada en ramas de funcionalidad.

Los cambios deben realizarse en ramas con nombres descriptivos y posteriormente integrarse en `main` mediante un Pull Request.

## Integración continua

GitHub Actions valida automáticamente los cambios realizados en las ramas de funcionalidad y en los Pull Requests dirigidos a `main`.
